# 📋 Course Registration Form (HTML)

A simple and responsive Course Registration Form built using **HTML** and **CSS**. This project demonstrates how to create a structured and styled form to collect personal and course details from users.



---

## 🚀 Features

- Collects personal details:
  - First Name
  - Last Name
  - Mobile Number
  - Email
  - Password and Confirm Password
  - Date of Birth, Age, Gender, and Country
- Course selection options:
  - Course Mode: Online or Offline
  - Course Type (Dropdown)
- Reset and Submit functionality

---

## 🛠️ Technologies Used

- **HTML5** for structure  
- **CSS3** for styling  
*(No JavaScript used in this version)*
